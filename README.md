# Simple XO

A small, playful Tic-Tac-Toe game designed for the browser.

[**Play the live demo**](https://tawan-chaidee.github.io/Simple-XO-game/)

## Features

- Local two-player gameplay
- Turn tracking for X and O
- Win and draw detection
- Winning-cell animation
- Reset and replay support
- Responsive board layout

## Stack

- HTML
- CSS
- Vanilla JavaScript
- GitHub Pages

## Run locally

Open `index.html` in a browser, or serve the directory with any static file server.

## Why this project is here

This is a compact front-end project and an intentional reminder that not every repository needs to be a large system. It is useful for demonstrating DOM interaction, game-state tracking, and CSS animation in a small codebase.
